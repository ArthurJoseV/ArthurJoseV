* **Garantia de Qualidade (QA):** Implementação de testes automatizados (unitários e de integração) para assegurar a estabilidade e o comportamento correto dos serviços.
* **Orquestração e Deploy:** Modelagem de infraestrutura, deploy de contêineres e configuração de proxies reversos em ambiente AWS.
